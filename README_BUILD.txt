TDT Viewer TextSync LFP Spectrogram v4 — Build and Run
======================================================

macOS
-----
Ready app: dist/TDT Viewer TextSync LFP Spectrogram v4.app
Ready ZIP: dist/TDT_Viewer_TextSync_LFP_Spectrogram_v4_macOS_arm64.zip

If rebuilding, double-click build_macos.command or run it from Terminal.
The local build is ad-hoc signed, not Apple-notarized. On first launch,
Control-click the app, choose Open, then confirm Open if macOS asks.

Windows x64
-----------
Copy the entire project folder to a Windows x64 computer with Python 3.12.
Double-click build_windows.bat. It creates:

  dist\TDT Viewer TextSync LFP Spectrogram v4\TDT Viewer TextSync LFP Spectrogram v4.exe
  dist\TDT_Viewer_TextSync_LFP_Spectrogram_v4_Windows_x64.zip

The whole dist folder must stay together; do not move only the EXE.
